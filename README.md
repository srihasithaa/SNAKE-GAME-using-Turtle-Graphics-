# 🐍 Snake Game (Python Turtle)

A simple and classic Snake Game built using Python's Turtle module.  
Inspired by the classic Nokia snake game.

---

## 🎮 Features
- Smooth snake movement
- Arrow key controls
- Random food spawning
- Score tracking
- Collision detection (wall + self)

---

## 📁 Project Structure
nokiasnake/
│── game.py
│── snake.py
│── food.py
│── scoreboard.py


---

## ▶️ How to Run

1. Make sure Python is installed (Python 3.x)
2. Clone or download this repository
3. Navigate to the project folder

```bash
cd nokiasnake
python game.py

---

## 🎯 Controls

- ↑ : Move Up  
- ↓ : Move Down  
- ← : Move Left  
- → : Move Right  

---

## 🧠 Game Logic

- Snake moves continuously forward
- Food appears randomly on screen
- Eating food:
  - Increases score
  - Extends snake length
- Game ends if:
  - Snake hits wall
  - Snake hits its own body
